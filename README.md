# nikotFiler（ニコットファイラー）

**操作は簡単に、画面はシンプルに。** Windows 向けのタブ型ファイラーです。

文字を読みやすい大きさに変え、2つのフォルダーを並べて作業できます。秀丸ファイラーのようなタブ操作を参考にした、独立した試作アプリです。

アイコンは、ニコッと笑う猫に「F」を重ねたデザインです。

> **0.1.0 プレビュー** — 開発初期の試作版です。まずはテスト用フォルダーでお試しください。未実装の機能や動作確認の範囲は下記に記載しています。

## できること

- 各画面の「＋」でタブを自由に追加。「×」・中クリック・Ctrl+W で閉じる。アプリ全体で最後の1枚は残し、ホームを勝手に開き直しません。空になった側は閉じて、残ったタブを1画面に表示します。
- 1画面／左右2画面を切り替え、境界をドラッグして幅を調整。
- ファイル画面の枠を縁取りで見分けやすく表示（既定 ON）。右上の「1画面／2画面 ▾」メニューで「枠の縁取りを表示」を ON／OFF にでき、次回起動時にも引き継ぎます。
- 「Aa」からアプリ全体の文字サイズを 80～250% に変更。数値入力、Ctrl+ホイールにも対応。
- フォルダー移動、戻る・進む、名前で絞り込み、列見出しによる並べ替え。
- コピー・移動・名前変更・新規フォルダー・ごみ箱への削除。実行前に対象と保存先を確認。同名項目は上書きしません。
- Ctrl+C／X／V のコピー・切り取り・貼り付け。Windows のファイルクリップボードを使用。
- ブックマーク、アプリ内の閲覧・操作履歴、タブと文字サイズの自動保存。履歴は検索でき、選んだ場所を開けます。

## ダウンロードと起動

[Releases](https://github.com/konikatsu/nikotFiler/releases) にプレビュー版の配布ファイルを掲載します。

最新の配布版は **ランタイム非同梱の Windows x64 版**です。先に [.NET Desktop Runtime 10（Windows x64）](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールしてください。対応する .NET 10 SDK が入っている場合は追加インストール不要です。

Release の `nikotFiler-0.1.0-win-x64-framework-dependent.zip` をダウンロードして**すべて展開**し、`nikotFiler.exe` を起動します。EXE と同じフォルダーの DLL・JSON も必要です。コンソール用の「.NET Runtime」だけでは WPF アプリは起動できないため、「.NET Desktop Runtime」を選んでください。

配布版は未署名です。組織や PC のアプリケーション制御によって実行できない場合があります。開発環境でもこの制御によりローカルの起動確認はブロックされています。組織のポリシーや警告を無効化せず、管理者が許可した環境で使用してください。

## 基本操作

| 操作 | キー |
|---|---|
| タブを追加／閉じる | Ctrl+T / Ctrl+W |
| 次のタブ | Ctrl+Tab |
| 履歴から開く | Ctrl+H |
| 左右の画面を切り替える | F6 |
| パスを入力／名前を絞り込み | Ctrl+L / Ctrl+F |
| 戻る／進む／上へ | Alt+← / Alt+→ / Alt+↑ |
| 再読込 | F5 |
| コピー／切り取り／貼り付け | Ctrl+C / Ctrl+X / Ctrl+V |
| 名前変更／ごみ箱へ | F2 / Delete |
| 文字を拡大・縮小 | Ctrl+ホイール / Ctrl+＋・− |
| 文字を標準サイズに戻す | Ctrl+0 |

上部の「コピー」「移動」は反対側に**表示中のフォルダー**を操作先にします。1画面の場合はフォルダー選択を開きます。確認画面で対象と保存先を確認してください。

履歴から移動するには、サイドバーの「閲覧・操作履歴」または Ctrl+H を押します。名前・パス・種類で絞り込み、項目をダブルクリックするか、選択して Enter／「この場所を開く」を押してください。フォルダー履歴はその場所、ファイル履歴はその親フォルダーを開きます。成功したコピー・移動・名前変更の履歴は操作先を開き、ごみ箱の履歴は元の親フォルダーを開きます。場所が見つからなければ履歴画面でエラーを表示します。

## 保存データ

設定・タブ・ブックマーク・履歴は `%LOCALAPPDATA%\nikotFiler` に保存します。操作履歴には実際のファイル名やパスが含まれます。これらは GitHub や外部サービスに送信しません。旧 HistoryFiler のデータは自動で変更・移行しません。

このアプリで行った操作のみ記録します。コピー等の操作記録が書き込めない場合は、ファイル変更を開始しません。

## 現在の制約

- 隠しファイル・システムファイルは表示しません。フォルダーツリー、3画面以上の分割、タブのドラッグ配置、SVN、Access 連携は未実装です。
- コピーを中止した場合や途中で失敗した場合、コピー先に一部の項目が残る場合があります。
- 異なるドライブ間での**フォルダー移動**には未対応です。ファイル操作の取り消し機能はありません。ごみ箱へ送った項目は Windows 側から戻せます。
- リンク・ジャンクションを含むフォルダーのコピーは拒否します。
- OS 標準のフォルダー選択画面には、アプリの文字サイズ設定が反映されません。
- 列幅・ウィンドウ位置・分割比率・一覧のスクロール位置は終了後には復元しません。タブ、文字サイズ、1／2画面、ウィンドウサイズ、ブックマークは保存します。
- 大規模フォルダーやネットワーク先での性能と、複数 DPI モニターでの実画面確認は今後の検証事項です。

## 開発

Windows と **.NET 10 SDK** が必要です。外部の NuGet ライブラリは使用していません。

```powershell
dotnet build NikotFiler.slnx -c Release
dotnet run --project src/NikotFiler.App
dotnet run --project tests/NikotFiler.Tests -c Release
```

回帰テストは一時フォルダー内のダミーファイルだけを使用します。コピー・移動・改名・ごみ箱・上書き防止・中止・履歴・設定復元と、タブ間の選択状態を確認します。ユーザーの実データは操作しません。

GitHub Actions では Windows 上でビルド・回帰テスト・配布 ZIP の作成を行います。`v*` タグでプレビュー Release を作成します。

```powershell
dotnet publish src/NikotFiler.App -c Release -r win-x64 --self-contained false -p:UseAppHost=true -o artifacts/nikotFiler-win-x64-framework-dependent
```

テスト時に設定を分離するには `nikotFiler.exe --data-dir <テスト用保存先> --folder <最初に開くフォルダー>` を指定できます。
