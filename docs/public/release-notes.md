# nikotFiler v0.1.0-preview.5

**笑顔の猫に「F」を重ねた新しいアイコン**を採用しました。Windows x64 のランタイム非同梱版です。

- EXE・メインウィンドウ・画面左上のロゴに同じデザインを使用します。
- Windows 用 ICO は16～256pxの9サイズを収録し、透過 PNG も用意しました。
- 画像の制作方法と生成プロンプトは `docs/public/icon-design-v1.md` に記録しています。

枠の縁取り設定と、これまでのタブ・履歴機能も利用できます。

- 枠の縁取りは既定で ON。操作中の画面は緑、そのほかの画面は落ち着いた色の縁取りで区別します。
- 右上の「1画面／2画面 ▾」メニューにある「枠の縁取りを表示」で ON／OFF を切り替えられます。
- 設定は自動保存し、次回起動にも反映します。従来の設定ファイルでは ON として読み込みます。
- OFF の場合も「操作中」の見出しを残し、タブや選択項目を維持します。

これまでのタブ・履歴機能も利用できます。

- アプリ全体で最後のタブ1枚は閉じません。「×」と右クリックの「閉じる」を無効表示にし、Ctrl+W・中クリックでも保護します。
- ほかにタブがあるときは閉じ、空になった側は整理して1画面にします。ホームを勝手に開き直さず、次回起動でも閉じた側を復元しません。
- 「閲覧・操作履歴」または Ctrl+H から、検索可能な履歴一覧を開けます。
- 履歴を選び、Enter・ダブルクリック・「この場所を開く」で移動できます。ファイルの履歴は親フォルダーを開きます。
- 履歴の参照はフォルダー移動だけを行い、過去のファイル操作を再実行しません。

## 起動方法

1. [.NET Desktop Runtime 10（Windows x64）](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールします。対応する .NET 10 SDK がある場合は追加インストール不要です。
2. `nikotFiler-0.1.0-win-x64-framework-dependent.zip` をすべて展開します。
3. 展開先の `nikotFiler.exe` を起動します。同じフォルダーの DLL・JSON も必要です。

配布 ZIP には .NET ランタイムを含みません。WPF アプリのため、コンソール用の「.NET Runtime」ではなく「.NET Desktop Runtime」を使用してください。
