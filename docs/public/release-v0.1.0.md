# nikotFiler 0.1.0 Preview

「操作は簡単に、画面はシンプルに」を目指した最初の Windows x64 向け試作版です。

- 自由に追加・閉じることができるタブと、1／左右2画面の切り替え。
- アプリ全体の文字サイズを80～250%で調整。
- 確認画面付きのコピー・移動・名前変更・ごみ箱・フォルダー作成。
- ブックマーク、閲覧・操作履歴、文字サイズとタブの自動保存。

ZIP をすべて展開して `nikotFiler.exe` を起動してください。.NET ランタイムを同梱しています。

開発初期の未署名プレビューです。アプリケーション制御で起動できない環境があります。まずはダミーファイルのフォルダーでお試しください。コピーの中止・失敗時にコピー先に一部が残る場合があります。異なるドライブ間のフォルダー移動と操作の取り消しは未対応です。

Windows CI のビルド・回帰テストを通過した成果物です。開発 PC ではアプリケーション制御により実画面の起動確認ができていません。文字拡大時の実画面、複数モニター、ネットワーク先での利用などは今後の検証対象です。

詳細・操作方法は [README](https://github.com/konikatsu/nikotFiler#readme) を参照してください。
